# Pilot Mobile — موقع الولاء وعجلة الجوائز 🎡

موقع احترافي لشركة **بايلوت موبايل (Pilot Mobile)** — كربلاء، العراق.
يجمع بيانات العملاء عبر نظام عجلة جوائز ذكية، مع لوحة تحكم إدارية كاملة.

الهوية: **أخضر زمردي + ذهبي + كريمي** | تصميم Premium بحركات 3D وزجاج (Glass).

---

## 🧩 المميزات

- **الصفحة الرئيسية:** شعار + هيرو ثلاثي الأبعاد + نص تسويقي + أزرار (خريطة/إنستغرام/تيك توك/اتصال).
- **عجلة الجوائز:** 10 جوائز، مؤثرات صوتية وحركية، **الجائزة يحددها السيرفر** (حماية من الغش).
- **التسجيل:** الاسم + رقم الهاتف + كود الفاتورة، مع تحقق كامل.
- **قاعدة البيانات:** حفظ الاسم/الهاتف/الفاتورة/التاريخ/الجائزة/عدد المشاركات.
- **الحماية:** منع استخدام الفاتورة مرتين (بشكل ذرّي)، تحقق من المدخلات، سجل عمليات (Logs).
- **لوحة التحكم:** إحصائيات + رسوم بيانية + عملاء (بحث) + فواتير (إضافة/توليد/حذف) + تعديل الجوائز + تصدير Excel.

## ⚙️ أوامر مفيدة

| الأمر | الوظيفة |
|------|---------|
| `npm run dev` | تشغيل الموقع للتطوير |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run db:studio` | فتح واجهة لتصفّح قاعدة البيانات |
| `npm run db:reset` | تصفير قاعدة البيانات وإعادة البيانات الأولية |

## ✏️ ما تحتاج تعدّله

1. **رقم هاتف الشركة:** في `src/lib/site.ts` → غيّر `phone` و `phoneDisplay`.
2. **الشعار الحقيقي:** حالياً الشعار مُعاد بناؤه بالكود. لاستخدام صورتك الأصلية، ضعها في `public/logo.png`.
3. **كلمة مرور الأدمن:** في `.env` غيّر `ADMIN_PASSWORD` ثم نفّذ `npm run db:reset`.

---

## 🗄️ التحويل إلى PostgreSQL (للإنتاج لاحقًا)

في `prisma/schema.prisma` غيّر `provider = "sqlite"` إلى `"postgresql"`،
وفي `.env` ضع رابط قاعدة PostgreSQL، ثم `npm run db:push`.
